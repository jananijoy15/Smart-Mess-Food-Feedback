# 🍱 Smart Mess Food Feedback

A simple and responsive web application that allows college students to view the daily mess menu, rate their food, and share feedback.

## Live Website Link
https://jananijoy15.github.io/Smart-Mess-Food-Feedback/

## ✨ Features

- 🍽️ Today's Menu
- ⭐ Food Rating
- 💬 Student Feedback
- 📊 Rating Summary
- 🏆 Top Rated Meal
- 💾 Local Storage
- 🗑️ Delete Feedback
- 📱 Mobile Responsive

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯 Objective

To collect student feedback about mess food and help improve the overall campus dining experience.
